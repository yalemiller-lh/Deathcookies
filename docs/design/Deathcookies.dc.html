On iPhone, a Shortcut adds "Save to Deathcookies" to the Share menu. Set it up once:

  1. Open the Shortcuts app and tap +. Name it Save to Deathcookies.
  2. Tap ⓘ, turn on Show in Share Sheet, and set it to receive Images only.
  3. Add the action Extract Text from Image (input: Shortcut Input).
  4. Add URL Encode (input: Text from Image).
  5. Add Text and type https://deathcookies.web.app/#quote=, then insert URL Encoded Text straight after it.
  6. Add Open URLs. Done.

Then: take a screenshot → Share → Save to Deathcookies. It opens in Safari; the first time, sign in there with your email and password.
